5. 关键发现
======================================================================

5.1 加密机制
  - 业务JS/HTML文件使用AES或类似算法加密
  - 加密文件以二进制密文形式存储
  - 文件头特征: 0xA4 0x7A 0xF0 0xC8... (login.html, create.html)
  - api.js 加密头: 0xB7 0x71 0x9E 0x87...
  - 运行时由MTL引擎解密后执行

5.2 存储Key发现 (keys.js)
  - mtl$exclusiveUserInfo     - 用户信息
  - mtl$saveExclusiveYhtInfo  - YHT认证信息
  - mtl$exclusiveDomain       - 服务器域名配置
  - mtl$exclusiveLanguage     - 语言设置
  - mtl$userFontSizeLevel     - 字体大小

5.3 数据库信息 (appletDatabase.js)
  - 数据库名: mtlApplet
  - 数据库文件: box://mtlAppletData.db
  - 加密密码: mtl$db
  - 使用模块: sqlCipher
  - 表结构:
    * mtl_dbinfo (version INTEGER)
    * resource_file_mapping (pkid, resourceId, fileId, filePath)

5.4 域名处理逻辑 (h5app.js)
  代码片段:
    var domainInfoStr = api.getPrefs({
        sync: true,
        key: 'mtl$exclusiveDomain'
    });
    if (domainInfoStr) {
        var domainInfo = JSON.parse(domainInfoStr);
        domain = domainInfo.domain;
    }
    // domain = 'https://bip-daily.yyuap.com/iuap-yonbuilder-mobile/';
    if (domain && domain.substr(domain.length - 1, 1) == '/') {
        domain = domain.substr(0, domain.length - 1);
    }
    api.ajax({ url: domain + ... })

  关键发现:
    - 域名从本地存储读取 (mtl$exclusiveDomain)
    - 存在硬编码的测试域名 (注释中):
      https://bip-daily.yyuap.com/iuap-yonbuilder-mobile/
    - 域名尾部会自动去除斜杠
    - 通过 api.ajax() 发送请求到 domain + API路径

10. 分析总结
======================================================================

10.1 技术栈
  - 框架: yonBuilder MTL (用友网络)
  - 渲染: apivm 虚拟DOM
  - 存储: SQLite + sqlCipher (密码: mtl$db)
  - 网络: api.ajax() (APICloud风格)
  - 推送: 华为Push + mtlPush

10.2 安全机制
  - 业务代码加密: JS/HTML文件使用AES类算法加密
  - 数据库加密: sqlCipher AES-256加密
  - 密钥硬编码: 数据库密码 'mtl$db' 硬编码在JS中
  - 运行时解密: 由MTL引擎在运行时解密执行

10.3 API接口获取难度
  [困难] 核心业务API被加密，无法静态分析提取
  需要以下方法才能获取:
    1. 动态抓包: 使用Frida/Charles抓取运行时HTTP请求
    2. 内存Dump: 从运行中的APP内存中提取解密后的JS
    3. 逆向MTL引擎: 分析MTL框架的解密算法和密钥
    4. Hook api.ajax(): 拦截JS层的网络请求函数

10.4 已知信息
